## Unictoos v0.1.0-alpha03

This release contains the Phase 2 and Phase 3 product-shell redesign.

### Visual and UX improvements

The app now uses a cohesive Unictoos visual system based on the supplied logo: dark ink surfaces, violet and magenta brand accents, cyan readiness signals, mint live states, amber attention states, and clearer typography hierarchy. The supplied logo is used throughout the branded Home, Studio, launcher, and splash surfaces.

The mobile workflow is now organized around Home, Scenes, Studio, Library, and Settings. Home presents broadcast readiness and quick actions. Studio provides a focused live-preview workspace with stream health cards, destination readiness, scene editing, and a clear Go Live control. Scenes now support portrait or landscape creation and source chips. Library and Settings provide clearer next-step surfaces for recordings, destinations, device behavior, credential protection, and privacy.

### Build details

- Application ID: `com.unictoai.unictoos`
- Version name: `0.1.0-alpha03`
- Build type: debug alpha
- Minimum Android version: Android 10 / API 29
- Target SDK: 35

### Important testing note

This remains an alpha debug build. Install it on a physical Android device and verify navigation, screen-capture consent, microphone input, destination setup, stream start/stop, and YouTube/Twitch/Kick ingest with a private or unlisted test stream before using it for an important broadcast.
